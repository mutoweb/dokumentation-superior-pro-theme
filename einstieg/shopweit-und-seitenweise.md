# Shopweit und seitenweise

Superior PRO steuert den Shop an zwei Stellen. Beide ergänzen sich.

## Theme-Manager

Unter **Inhalte → Themes → Superior PRO Theme** liegen die Werte, die für den ganzen Verkaufskanal gelten: Farben, Schriften, Header, Navigation, Footer, Produktboxen, Formulare und der eigene Code im Head.

Eine Änderung hier gilt auf jeder Seite, die dieses Theme nutzt. Die Produktbox auf der Startseite, in der Kategorie und in der Suche sieht danach gleich aus.

## Erlebniswelten

Unter **Inhalte → Erlebniswelten** baust du einzelne Seiten: Startseite, Kategorien, Landingpages und Shopseiten. Eine Sektion, ein Block oder ein Element gilt nur auf der Seite, auf der du es einsetzt.

Dieselben Elemente kannst du auf vielen Seiten verwenden. Jede Seite speichert ihre eigene Füllung. Ein Teaser auf der Startseite ändert den Teaser auf einer Landingpage nicht.

## Was wo hingehört

| Du willst …                                            | Dafür nutzt du …                                |
| ------------------------------------------------------ | ----------------------------------------------- |
| die Primärfarbe, den Header oder die Produktbox ändern | den Theme-Manager                               |
| eine Startseite mit Teasern, FAQ und Galerie bauen     | eine Erlebniswelt                               |
| einen Hinweis nur auf einer Seite ausgeben             | das Element HTML und CSS in dieser Erlebniswelt |
| ein Meta-Tag oder eine Schrift auf jeder Seite         | den Tab Custom Code                             |
| vier Vorteile über dem Footer                          | den Tab USP und die Textbausteine               |
| den Footer umbauen                                     | den Tab Footer                                  |

## Farben werden weitergegeben

Viele Farbfelder im Theme zeigen auf die **Primärfarbe**, die **Sekundärfarbe** oder die **Rahmenfarbe** aus den [Grundeinstellungen](../theme-einstellungen/grundeinstellungen.md). Solange du das jeweilige Feld nicht selbst setzt, zieht es mit, wenn du die Quelle änderst.

Ein [Farb-Preset](../theme-einstellungen/grundeinstellungen.md#farb-preset) setzt eine ganze Palette auf einmal. Danach bleibt jede Farbe einzeln änderbar.

In den Erlebniswelten gilt für Teaser Image Box, Accordion, Tabs, Seiten-Header und Lauftext:

* Ein leeres Farbfeld übernimmt die Theme-Farben.
* Eine Farbe, die du im Element setzt, gilt nur für dieses Element.

In der Vorschau der Administration siehst du dafür neutrale Platzhalter, sofern du keine eigene Farbe gesetzt hast. Im Shop greifen die Theme-Farben.

{% hint style="info" %}
Die Überschriften H1 bis H6 starten mit der Überschriftfarbe aus dem Tab Typografie. Färbst du eine Stufe einzeln, löst sie sich von dieser Farbe. Die übrigen Stufen ziehen weiter mit.
{% endhint %}
