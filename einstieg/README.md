# Einstieg

Bevor du einzelne Farben setzt, lohnt sich ein Blick darauf, wo eine Einstellung wirkt.

* [Shopweit und seitenweise](shopweit-und-seitenweise.md) trennt den Theme-Manager von den Erlebniswelten und erklärt, wie Farben weitergegeben werden.
* [Theme zuweisen und speichern](theme-zuweisen.md) beschreibt, wie das Theme an einem Verkaufskanal hängt und wann eine Änderung im Shop sichtbar wird.
