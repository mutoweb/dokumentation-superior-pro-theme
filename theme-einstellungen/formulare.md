# Formulare

Im Tab **Formulare** färbst du die Eingabefelder im Shop an einer Stelle. Das gilt für Anmeldung, Kasse, Kontakt und die übrigen Formulare.

Ausgenommen sind zwei Felder, damit Kopf und Footer unabhängig bleiben:

* Das Suchfeld im Header. Dessen Farben liegen im Tab [Header](header.md).
* Das E-Mail-Feld im Newsletter. Dessen Farben liegen unter [Newsletter und Social Media](footer/newsletter-social.md). Es startet mit den Werten aus diesem Tab und lässt sich danach lösen.

## Farben

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Fläche des Feldes im Ruhezustand |
| Hintergrundfarbe (focus) | Die Fläche, während das Feld aktiv ist |
| Text | Die eingetippte Schrift |
| Text (focus) | Die Schrift im Fokus |
| Rahmenfarbe | Der Rand im Ruhezustand |
| Rahmenfarbe (focus) | Der Rand im Fokus |
| Placeholder Farbe | Der Hinweistext, solange das Feld leer ist |

Die Abrundung der Felder kommt aus **Inputs** unter [Grundeinstellungen](grundeinstellungen.md), nicht aus diesem Tab. Buttons auf den Formularen nutzen den Button-Radius und die Farben des Kauf-Buttons oder der Primärfarbe, je nachdem, welcher Button es ist.

Pflichtfeld-Markierung, Fehlermeldung und die Beschriftung der Felder kommen aus Shopware und aus den Textbausteinen. Das Theme setzt dafür keine eigenen Texte.
