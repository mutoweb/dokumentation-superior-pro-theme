# Farben und Schrift im Footer

Im Tab **Footer** färbst du die Spalten und die schmale Leiste ganz unten. Welche Spalten sichtbar sind, stellst du unter [Aufbau](aufbau.md) ein.

## Footer

### Farben

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Fläche des Footers |
| Überschriftfarbe | Die Spaltenüberschriften |
| Überschriftfarbe (hover) | Überschriften, wenn sie verlinkt sind und der Zeiger darüber liegt |
| Textfarbe | Absätze in den eigenen Spalten und im Newsletter-Text |
| Link Farbe | Links im Footer |
| Link Farbe (hover) | Links, wenn der Zeiger darüber liegt |
| Rahmen Farbe (mobile) | Die Trennlinie zwischen den Spalten auf kleinen Bildschirmen |

### Typografie Überschrift

Diese Werte gelten für die Spaltenüberschriften, nicht für die H1 bis H6 im Inhalt.

| Feld | Wirkung |
| --- | --- |
| Schriftgröße Multiplikator | Die Größe gegenüber der Standard-Schriftgröße |
| Schriftstärke | Die Strichstärke |
| Buchstabenabstand | Der Zeichenabstand |
| Text transformieren | **Normal** oder **Großbuchstaben** |
| Schriftart | Die Schrift der Überschriften. Leer oder der Theme-Wert nutzt die Überschriftenschrift aus dem Tab Typografie. |

### Typografie Text

Dieselben Felder gibt es für den Fließtext im Footer, zusätzlich mit **Zeilenhöhe (Faktor)**. So kann der Footer eine andere Größe haben als der Seitentext, ohne die Überschriften H1 bis H6 zu ändern.

## Footer Bottom

**Footer Bottom** ist die schmale Leiste ganz unten, meist mit dem Copyright-Text.

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Fläche der Leiste |
| Textfarbe | Der Copyright-Text |
| Link Farbe | Links in dieser Leiste |
| Link Farbe (hover) | Dieselben Links bei Hover |

Den Text selbst pflegst du als `mutoTheme.footer.copyrightText`. HTML, zum Beispiel ein Link auf deine Agentur, ist dort erlaubt.

Newsletter-Farben und Social-Icon-Farben haben eigene Blöcke. Sie stehen auf der Seite [Newsletter und Social Media](newsletter-social.md).
