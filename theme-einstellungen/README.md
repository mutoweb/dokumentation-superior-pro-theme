# Theme einrichten

<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

Die Seiten in dieser Gruppe folgen den Tabs im Theme-Manager. Du öffnest sie unter **Inhalte → Themes → Superior PRO Theme**.

* [Grundeinstellungen](grundeinstellungen.md) für Farben, Presets, Header-Grundentscheidungen, Boxed-Modus, TopBar, Cookie-Hinweis, Abrundung und Preloader
* [Typografie](typografie.md) für Schriften und die Überschriften H1 bis H6
* [Header](header.md) für Logo, Suchfeld und TopBar
* [Navigation](navigation.md) für Hauptnavigation und Flyout
* [Footer](footer/) für Spalten, Newsletter und Social Media
* [USP](usp.md) für die Vorteilsleiste
* [Produktlisting](produktlisting/) für Produktboxen, Sidebar und Spaltenzahl
* [Produktseite](produktseite.md) für die Reiter auf der Produktdetailseite
* [Formulare](formulare.md) für die Eingabefelder im Shop
* [Verschiedenes](verschiedenes.md) für Slider, Offcanvas, Cards, Merkzettel und Seitenzahlen
* [Custom Code](custom-code.md) für eigenes HTML, CSS und JavaScript auf jeder Seite

Wie du das Theme zuweist und speicherst, steht im [Einstieg](../einstieg/theme-zuweisen.md).
