# Sidebar-Filter

Der Filterbereich in der Produktliste hat eigene Farben. Du findest sie im Tab **Produktlisting** unter **Sidebar Filter**.

Die Eigenschaften, Preise und Hersteller, nach denen gefiltert wird, kommen aus Shopware. Das Theme färbt nur die Darstellung.

## Farben

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Filtergruppe im Ruhezustand |
| Text | Beschriftung und Werte im Ruhezustand |
| Hintergrundfarbe (active) | Ein gesetzter Filter |
| Text (active) | Die Schrift eines gesetzten Filters |
| Hintergrundfarbe (hover) | Die Fläche, wenn der Zeiger darüber liegt |
| Text (hover) | Die Schrift bei Hover |
| Border | Die Trennlinie |
| Border (hover) | Die Trennlinie bei Hover |

## Abstand

**Margin Bottom (in px)** ist der Abstand unter dem Filterblock.

Während die Liste nach einem Filter neu lädt, ersetzen die Produktboxen ihren Inhalt durch einen Ladekreis in der Primärfarbe. Die Filterleiste selbst bleibt stehen. Für diesen Ladezustand gibt es kein eigenes Farbfeld.
