# Sidebar-Navigation

Die Kategorie-Navigation in der Seitenleiste einer Produktliste hat eigene Farben und eine Typografie je Ebene. Du findest sie im Tab **Produktlisting** unter **Sidebar Navigation**.

Die Hauptnavigation im Header stellst du im Tab [Navigation](../navigation.md) ein. Beide Bereiche teilen sich die Kategorien aus Shopware, sehen aber unabhängig aus.

## Farben

Die Zustände gelten für die Einträge der Seitenleiste.

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Der Eintrag im Ruhezustand |
| Text | Die Schrift im Ruhezustand |
| Hintergrundfarbe (hover) | Der Eintrag, wenn der Zeiger darüber liegt |
| Text (hover) | Die Schrift bei Hover |
| Hintergrundfarbe (active) | Die aktuelle Kategorie |
| Text (active) | Die Schrift der aktuellen Kategorie |
| Border | Die Trennlinie |
| Border (hover) | Die Trennlinie bei Hover |

## Typografie je Ebene

Ebene 0 ist die oberste Kategorie in der Leiste. Darunter folgen Ebene 1, Ebene 2, Ebene 3 und Ebene 4. Für jede Ebene stellst du ein:

| Feld | Wirkung |
| --- | --- |
| Schriftgröße Multiplikator | Die Größe gegenüber der Standard-Schriftgröße |
| Schriftstärke | Die Strichstärke |
| Buchstabenabstand | Der Zeichenabstand |
| Text transformieren | **Normal** oder **Großbuchstaben** |

Eine tiefere Ebene kannst du kleiner und leichter setzen, damit die Hierarchie in der Leiste lesbar bleibt.

## Abstand

**Margin Bottom (in px)** ist der Abstand unter der gesamten Seitenleiste-Navigation, bevor der Filter oder der nächste Block beginnt. Auf Kategorieseiten bleibt zwischen Sidebar und Produktliste ein fester Abstand. Diesen Spalt stellst du nicht in diesem Feld ein.
