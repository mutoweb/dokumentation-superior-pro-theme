# Produktlisting

Im Tab **Produktlisting** gestaltest du Kategorie- und Suchergebnisseiten: die Produktbox, die Sidebar und wie viele Produkte in einer Reihe stehen.

* [Produktboxen](produktboxen.md) für Bild, Inhalt, Farben und den Scroll-Effekt
* [Sidebar-Navigation](sidebar-navigation.md) für die Kategorien in der Seitenleiste
* [Sidebar-Filter](sidebar-filter.md) für die Filter
* [Produkte pro Reihe](produkte-pro-reihe.md) für die Spaltenzahl und den Abstand

Die Reiter auf der Produktdetailseite liegen im Tab [Produktseite](../produktseite.md), nicht hier.
