# Verschiedenes

Im Tab **Verschiedenes** liegen Farben und der Slider-Übergang, die an mehreren Stellen im Shop auftauchen und keinem einzelnen Bereich wie Header oder Footer zugeordnet sind.

## Slider und Karussell

### Übergang

**Übergang** gilt für den Bildslider von Shopware in den Erlebniswelten.

| Auswahl | Wirkung |
| --- | --- |
| Schieben | Die Bilder rücken weiter. Das ist der Ausgangswert. |
| Fade | Die Bilder blenden ineinander über. |

Produktgalerie und Produkt-Slider schieben weiter, auch wenn du hier Fade wählst. Der [Bild-Slider mit Text](../erlebniswelten/bild-slider.md) hat einen eigenen Übergang am Element und folgt diesem Feld nicht.

### Pfeilnavigation

Die Pfeile von Bild-Slider, Produkt-Slider und Galerie sitzen in der Buttonfläche mittig.

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Fläche des Pfeils |
| Icon Farbe | Der Pfeil |
| Hintergrundfarbe (hover) | Die Fläche, wenn der Zeiger darüber liegt |
| Icon Farbe (hover) | Der Pfeil bei Hover |

Der Button nach oben, der beim Scrollen erscheint, nutzt dieselbe Fläche. Der Pfeil sitzt darin vertikal mittig.

### Punktenavigation

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Der Punkt im Ruhezustand |
| Hintergrundfarbe (hover) | Der Punkt bei Hover und der aktive Punkt |

## Offcanvas

Seitenleisten wie der Warenkorb oder die mobile Navigation schließen über einen Button. Unter **Offcanvas** setzt du die **Hintergrundfarbe** dieses Schließen-Buttons. Schrift und Icon wählen automatisch eine lesbare Kontrastfarbe dazu. Eine eigene Textfarbe gibt es nicht.

Das Löschen-Icon im Warenkorb sitzt mittig in seiner Fläche. Dafür gibt es kein eigenes Feld.

## Cards

**Login und Checkout** färbt die Karte auf der Anmeldeseite und die Zusammenfassung im Checkout. Der Ausgangswert ist die Rahmenfarbe aus den Grundeinstellungen.

**Kundenkonto** färbt die Karten in Profil und Übersicht. Ohne eigene Farbe bleiben sie durchsichtig. Sobald du eine Farbe setzt, bekommen die Karten automatisch einen Innenabstand von 1 rem.

## Tooltip

**Tooltip Farben** gelten für die kleinen Hinweise an Icons, zum Beispiel im Header und an den Social-Icons.

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Fläche des Hinweises |
| Textfarbe | Die Schrift im Hinweis |

Ob die Hinweise im Header überhaupt erscheinen, entscheidet **Zeige Icon Tooltip** im Tab [Header](header.md).

## Merkzettel

**Merkzettel Icon Farben** setzen das Herz auf dem Produktbild.

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe | Die Fläche hinter dem Icon |
| Iconfarbe | Das Herz |
| Hintergrundfarbe (hover) | Die Fläche bei Hover |
| Iconfarbe (hover) | Das Herz bei Hover |

Der Button zum Entfernen auf der Merkzettel-Seite sitzt an derselben Bildecke wie der Button zum Hinzufügen und übernimmt den Button-Radius aus den Grundeinstellungen. Das Kreuz und das Verhalten bleiben die von Shopware.

## Seitenzahlen

**Seitenzahlen Farben** färben die Blätter-Navigation in Produktlisten. Seitenzahlen und Pfeile sitzen mittig in einem festen Button.

| Feld | Wirkung |
| --- | --- |
| Hintergrundfarbe (default) | Die Seite im Ruhezustand |
| Textfarbe (default) | Die Ziffer im Ruhezustand |
| Hintergrundfarbe (hover) | Die Seite, wenn der Zeiger darüber liegt |
| Textfarbe (hover) | Die Ziffer bei Hover |
| Hintergrundfarbe (active) | Die aktuelle Seite |
| Textfarbe (active) | Die Ziffer der aktuellen Seite |

Die Abrundung kommt vom Button-Radius in den Grundeinstellungen.
