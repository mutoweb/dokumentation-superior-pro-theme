# Leeres Element

Das **Leere Element** ist ein Platzhalter. In der Zeichenfläche steht „CMS Element wählen“. Im Shop gibt die Spalte nichts aus, sie nimmt keinen sichtbaren Inhalt ein.

Neue Raster unter **+ Spalten (SuperiorPRO)** starten damit. Du tauschst den Platzhalter über **Element tauschen** gegen Text, Bild oder ein Superior-PRO-Element. Siehe [Elemente einfügen und tauschen](elemente-tauschen.md).

Dasselbe Element kannst du in jede andere Spalte legen, wenn eine Fläche leer bleiben soll, zum Beispiel eine Lücke in einem ungleichen Raster. Es hat keine Einstellungen und keine Farben.

Gespeicherte Seiten behalten ihre bisherigen Inhalte. Nur neu eingefügte Spaltenraster starten leer. Ein Layout, das schon einen Text in der Spalte hat, wird durch ein Update nicht auf das leere Element umgestellt.
