# Erlebniswelten

Die Bausteine von Superior PRO liegen in den Erlebniswelten unter drei Kategorien:

* **+ Elemente (SuperiorPRO)** enthält fertige Blöcke, in denen das passende Element schon sitzt.
* **+ Spalten (SuperiorPRO)** enthält leere Raster von einer bis sechs Spalten.
* **+ Layout-Blöcke (SuperiorPRO)** enthält verschachtelte Raster, zum Beispiel eine große Fläche neben zwei kleineren.

Das Newsletter-Formular ist kein Erlebniswelt-Element. Es sitzt im Footer und ist auf der Seite [Newsletter und Social Media](../theme-einstellungen/footer/newsletter-social.md) beschrieben.

{% hint style="info" %}
Leere Farbfelder in Teaser Image Box, Accordion, Tabs, Seiten-Header und Lauftext übernehmen die Farben aus dem Theme. Eine Farbe, die du im Element setzt, überschreibt das. In der Administration siehst du dafür neutrale Platzhalter, im Shop die Theme-Farben.
{% endhint %}
