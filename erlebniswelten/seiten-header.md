# Seiten- und Kategorie-Header

Der **Seiten Header** ist ein großer Titelbereich mit Bild, Text und Klickpfad. Du setzt ihn oben auf Kategorieseiten, Landingpages oder Inhaltsseiten.

Ein fertiger Block liegt unter **+ Elemente (SuperiorPRO)** als **Seiten Header / Kategorie Header**.

## Inhalt

**Bild** und **Text** füllst du direkt im Element. In Kategorie-Erlebniswelten kannst du beide Felder per Zuordnung an die Kategorie binden. Dann kommen Kategoriebild und Kategoriebeschreibung automatisch. Eine feste Eingabe ersetzt die Zuordnung.

Ohne Bild zeigt der Header nur Text und Klickpfad. Die Fläche nutzt dann das Overlay.

Auf der Startseite ist der Klickpfad ausgeblendet, damit ein Banner ohne Abstand unter der Navigation beginnen kann.

## Einstellungen

| Feld | Wirkung |
| --- | --- |
| Textfarbe | Farbe von Überschrift und Text. Leer nutzt eine Kontrastfarbe zur Overlay-Farbe. |
| Overlay Farbe | Die Fläche über dem Bild. Leer nutzt die Primärfarbe. |
| Overlay Transparenz | Wie stark das Bild durch die Fläche scheint. Ein höherer Wert deckt das Bild stärker ab. |
| Abstand oben | Der Innenabstand über dem Text, in Pixel. Damit rückst du die Schrift vom oberen Rand weg. |
| Text Ausrichtung | **linksbündig**, **zentriert** oder **rechtsbündig** |
| Klickpfad Ausrichtung | Dieselbe Auswahl für den Breadcrumb. Text und Pfad dürfen unterschiedlich stehen. |
| Parallax | **Ja** lässt das Hintergrundbild dieses Elements beim Scrollen stehen. **Nein** scrollt das Bild mit. |

Eine gesetzte Overlay- oder Textfarbe gilt nur für dieses Element. In der Administration siehst du bei leeren Farben ein schwarzes Overlay mit weißer Schrift. Im Shop greifen Primärfarbe und Kontrast.

Dieser Schalter ist nicht das Parallax-Feld der Sektion. Die Sektion kann das Bild zusätzlich langsam mitlaufen lassen. Beides ist auf der Seite [Parallax](parallax.md) beschrieben.

Die Schriftgrößen im Header folgen den Überschriften aus dem Tab [Typografie](../theme-einstellungen/typografie.md). Eine eigene Schriftgröße gibt es an diesem Element nicht.
