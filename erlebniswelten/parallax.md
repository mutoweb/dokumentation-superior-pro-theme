# Parallax

<figure><img src="../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

Für eine Sektion mit Hintergrundbild gibt es unter dem Bildmodus das Feld **Parallax**.

| Auswahl  | Wirkung                                                                                     |
| -------- | ------------------------------------------------------------------------------------------- |
| Aus      | Das Bild scrollt mit der Sektion. Eine vorhandene Parallax-Klasse wird entfernt.            |
| Fixiert  | Das Bild bleibt beim Scrollen stehen.                                                       |
| Parallax | Das Bild bewegt sich langsamer als der Inhalt, solange die Sektion durch das Fenster läuft. |

Es gilt immer nur eine der beiden Bewegungen. Andere Klassen bleiben. Du kannst die Klasse auch weiterhin direkt eintragen: `muto-parallax` für Fixiert und `muto-parallax-scroll` für Parallax. Stehen beide Klassen im Feld, gilt die letzte.

## So richtest du es ein

1. Klicke links auf das Sektions-Symbol.
2. Wähle unter **Hintergrundbild** dein Bild.
3. Stelle **Parallax** auf **Fixiert** oder **Parallax**.
4. Speichere die Erlebniswelt.

Die Bewegung bleibt langsam und nutzt nur einen Teil des Bildüberstands. Der Ausschnitt bleibt im Foto. Ein Bild, das die Fläche nur knapp füllt, wird leicht vergrößert, damit kein leerer Rand entsteht.

Der [Mischmodus](hintergrund-mischen.md) gilt auch bei Parallax. Die Bildebene behält die Hintergrundfarbe der Sektion.

Der Seiten-Header hat zusätzlich einen eigenen Schalter **Parallax** in den Element-Einstellungen. Der lässt das Bild dieses Elements stehen. Die Klassen auf dieser Seite sind für die Sektion gedacht, nicht für den Seiten-Header.
