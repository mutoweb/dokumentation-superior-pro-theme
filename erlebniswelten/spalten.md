# Spalten

Unter **+ Spalten (SuperiorPRO)** liegen Raster von einer bis sechs Spalten. Die Umbrüche für Desktop, Tablet und Smartphone sind vorbereitet. Auf dem Smartphone stehen die Spalten untereinander. Auf dem Tablet folgen sie der mittleren Breite: eine Spalte, wo das Raster nur für Desktop gilt, zwei gleiche Spalten, wo das Raster halbe Spalten vorsieht.

Neue Raster starten mit dem [Leeren Element](leeres-element.md). In der Zeichenfläche steht „CMS Element wählen“, im Shop bleibt die Spalte leer. Den Inhalt tauschst du je Spalte über **Element tauschen**. Siehe [Elemente einfügen und tauschen](elemente-tauschen.md).

## Verfügbare Raster

Die Zahlen sind Zwölftel der Zeile, wie im Shopware-Raster. 12 ist die volle Breite, 6 ist die Hälfte, 4 ist ein Drittel.

| Block | Aufteilung auf dem Desktop |
| --- | --- |
| Spalten 12 | eine Spalte über die volle Breite |
| Spalten 6-6 | zwei gleiche Spalten |
| Spalten 4-4-4 | drei gleiche Spalten |
| Spalten 3-3-3-3 | vier gleiche Spalten |
| Spalten 2-2-2-2-2-2 | sechs gleiche Spalten |
| Spalten 3-9 und 9-3 | eine schmale und eine breite Spalte |
| Spalten 4-8 und 8-4 | eine schmale und eine breite Spalte |
| Spalten 5-7 und 7-5 | zwei ungleiche Spalten |
| Spalten 3-3-6, 6-3-3 und 3-6-3 | drei Spalten, eine davon doppelt so breit |
| Spalten 2-8-2 | schmale Ränder und eine breite Mitte |
| Spalten 7 zentriert | eine Spalte mit sieben Zwölfteln, mittig |
| Spalten 9 zentriert | eine Spalte mit neun Zwölfteln, mittig |

**Spalten 7 zentriert** und **Spalten 9 zentriert** liegen ab Desktop in der Mitte der Zeile. Darunter, also auf Tablet und Smartphone, nehmen sie die volle Breite ein. Beide starten mit dem leeren Element.

Den Abstand zwischen den Spalten stellst du am Block ein. Siehe [Spaltenabstände](spaltenabstaende.md). In einer Sektion über die volle Breite bleibt dieser Abstand erhalten, der Inhalt klebt nicht über den Bildschirmrand hinaus.

Die Administration bricht die Spalten in der Mobil- und Tablet-Vorschau so um wie der Shop. Was du in der Geräteansicht siehst, ist die Aufteilung, die Besucher sehen.
