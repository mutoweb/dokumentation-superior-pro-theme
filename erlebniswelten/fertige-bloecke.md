# Fertige Blöcke

Unter **+ Elemente (SuperiorPRO)** liegen Blöcke, in denen das passende Element schon eingesetzt ist. Du füllst sie nur noch.

| Block | Inhalt | Startwerte |
| --- | --- | --- |
| Seiten Header / Kategorie Header | ein Seiten-Header über die volle Breite | leeres Bild und leerer Text |
| Teaser Image Box 2, 3 oder 4 Spalten | gleich viele Teaser nebeneinander | Box-Format 1:1 |
| Accordion | Text links, Accordion rechts | ein Eintrag mit Platzhalter |
| Tabs | ein Tab-Element über die volle Breite | ein Reiter mit Platzhalter |
| Erweitertes Text-Element 2, 3 oder 4 Spalten | Textkacheln | zentrierter Platzhalter, heller Hintergrund, vertikal mittig, Hintergrund nur um Inhalt aus |
| Bild und erweitertes Text-Element 2, 3 oder 4 Spalten | je Spalte ein Bild und darunter eine Textkachel | Bild behält seine Höhe, Text liegt direkt am Bild, Hintergrund leicht gedeckt |
| Bildergalerie | eine Galerie über die volle Breite | ohne Bilder |
| Lauftext | ein Lauftext über die volle Breite | leere Farben, Theme-Farben im Shop |
| Bild-Slider mit Text | ein Slider über die volle Breite | Mindesthöhe 600 px, Übergang Fade |

Neue Blöcke dieser Art starten ohne eigenen Seitenrand links und rechts, so wie die Standard-Blöcke von Shopware. Einen Abstand zwischen den Spalten setzt du über **Spaltenabstand**. Siehe [Spaltenabstände](spaltenabstaende.md).

In den Bild-Text-Blöcken kleben Bild und Text an der gemeinsamen Kante. Der Element-Radius entfällt dort. Bei Mindesthöhe wächst die Box bis zur längsten Spalte. Tauschst du Bild und Text, wandert die eckige Kante mit. Dasselbe gilt, wenn du den Text gegen eine Teaser Image Box tauschst.

Die Raster unter **+ Spalten (SuperiorPRO)** starten mit dem [Leeren Element](leeres-element.md). Die verschachtelten Raster liegen unter **+ Layout-Blöcke (SuperiorPRO)** und sind auf der Seite [Layout-Blöcke](layout-bloecke.md) beschrieben.

Passt keiner der fertigen Blöcke, baust du das Raster selbst und tauschst das Element in der Spalte. Siehe [Elemente einfügen und tauschen](elemente-tauschen.md).
